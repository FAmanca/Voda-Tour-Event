# Memory - 20 August 2026

## Context & Objectives
- Focus on security hardening and operational resilience for both Profesional-Indonesia and Vodatrip.
- Mitigate Registration Bomb / Bot attacks on WordPress.
- Establish a bulletproof automated off-site backup for Vodatrip's Postgres and Directus uploads.
- Address copyright/media legalities through a public Media Policy page.

## Key Changes & Implementations

### 1. Profesional-Indonesia Security (WordPress)
- **Turnstile Integration:** Implemented Cloudflare Turnstile on both frontend (DOM logic) and backend (`functions.php`) for custom login and registration forms to stop bot registration bombs.
- **WP-Login Hardening:** Disabled "Anyone can register" to lock down the core WordPress registration flow.
- **Wordfence Recommendation:** Advised installing Wordfence Free as a PHP-level WAF for the shared hosting environment since CrowdSec engine cannot be installed without root access.

### 2. Vodatrip Infrastructure & Security
- **Automated Off-site Backup:**
  - Created a shell script (`/opt/backup/auto_backup.sh`) on the production server.
  - Script extracts PostgreSQL database via `docker exec pg_dump`.
  - Script extracts Directus file uploads via `docker cp`.
  - Compresses into a `.tar.gz` archive.
- **Rclone & OAuth Setup:**
  - Configured `rclone` with Google Drive using a custom OAuth Client ID (bypassing the deprecated shared client ID and Service Account quota limits).
  - Used `drive.file` scope to ensure Rclone only has access to the specific backup folder it created.
- **Retention Policy:**
  - Added `rclone delete drive_backup:Vodatrip_Backup_Server --min-age 7d` to automatically purge backups older than 7 days, maintaining disk space below 1.5GB to avoid storage exhaustion on the Google Drive.
- **Cronjob:** Scheduled the backup to run daily at 2:00 AM (`0 2 * * *`) with logs piped to `backup_log.txt`.
- **CrowdSec:** Validated that CrowdSec is actively blocking malicious bot scanners (e.g., `netgear_rce` from international IPs) hitting the raw server IP. Discussed Nginx real-ip forwarding (to be implemented next).

### 3. Vodatrip Frontend Updates
- **Media Policy Page:** Created `apps/web/src/pages/media-policy.astro` with a professional DMCA/Takedown policy.
- **Content Strategy:** Flipped the narrative to transparently state that most imagery is from the internet (Creative Commons/Illustration) and only specific event photos are proprietary.
- **Footer Link:** Injected the Media Policy link into the copyright bar in `apps/web/src/components/Footer.astro`.
