# Memory: 5 Agustus 2026

## Tugas Selesai
1. **Konfigurasi DNS-AID & DNSSEC:**
   - Menambahkan HTTPS/SVCB record di Cloudflare untuk `api.vodatrip.id`.
   - Mengaktifkan DNSSEC di Nevacloud (registrar) menggunakan data DS Record dari Cloudflare.

2. **Server Analytics (GoAccess):**
   - Menambahkan kontainer `goaccess` di `docker-compose.prod.yml`.
   - Mengonfigurasi Nginx untuk secara eksplisit menulis log ke `/var/log/nginx/access_real.log` (menghindari isu symlink stdout/stderr bawaan *image* Docker Nginx).
   - Menghindari masalah proksi WebSocket Cloudflare dengan menjalankan GoAccess dalam `while true` loop statis (di-refresh setiap 10 detik).
   - Mengamankan rute `/stats/` di Nginx menggunakan Custom Rule WAF Cloudflare (IP Whitelisting) untuk mencegah kebocoran data trafik.

3. **Server Monitoring (Netdata):**
   - Meng-install agen Netdata secara *native* di VPS menggunakan `kickstart.sh`.
   - Node diklaim melalui Netdata Cloud (`app.netdata.cloud`) untuk menghindari pembukaan port internal (19999).

4. **CI/CD Reliability:**
   - Menambahkan `docker compose restart nginx` pada pipeline GitHub Actions agar IP statis dari kontainer lain (*race condition* saat startup) ter-refresh.
   - Meningkatkan waktu jeda *health check* Directus di pipeline untuk mengakomodir *boot time* yang lambat.

## Catatan Penting untuk AI Berikutnya
- **Jangan** mencoba menggunakan WebSocket untuk GoAccess di belakang Cloudflare kecuali siap untuk repot dengan HTTP Headers dan URI Rewriting yang rentan patah. Metode statis 10 detik terbukti jauh lebih stabil.
- Nginx log default di *image* Alpine adalah symlink ke `/dev/stdout`. **Selalu buat file log kustom** (`access_real.log`) jika ingin diproses oleh analyzer seperti GoAccess.
- Akses monitoring Netdata jangan diproksi lewat Nginx; gunakan Netdata Cloud untuk keamanan maksimal.
