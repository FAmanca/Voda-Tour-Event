# Memory Log: 2026-07-27 — Major Directus Extensions UI/UX Rewrite & Hybrid Layout System

## 1. Ringkasan Sesi
Pada sesi ini, tim berhasil menyelesaikan transformasi besar pada antarmuka admin Directus, khususnya untuk modul kustom `article-editor` (Artikel Editor & SEO Analyzer Ala Yoast/RankMath) dan penyempurnaan alur pengembangan ekstensi Directus secara keseluruhan.

## 2. Pencapaian & Solusi Teknis

### A. Perbaikan Bug Kritis (Bug Fixes)
1. **TipTap Word-Wrap & Overflow Fix**:
   - Masalah: Teks panjang tanpa spasi (seperti URL atau string kode) menembus batas kanvas editor dan menyebabkan scrollbar horisontal yang merusak tampilan kertas.
   - Solusi: Menerapkan selector `:deep(.ProseMirror)` pada CSS dengan kombinasi `word-wrap: break-word; overflow-wrap: break-word; word-break: break-word; white-space: pre-wrap;` dan `outline: none;`.
2. **Scrollbar & Layout Height**:
   - Menjamin bahwa seluruh kontainer modul (`.dashboard-view` dan `.editor-view`) memiliki handling `overflow-y: auto` dengan ketinggian 100% yang tepat.
3. **Featured Image 0px Collapse Fix**:
   - Masalah: Gambar cover di dalam kanvas menghilang (tinggi 0px) karena flex container dengan `overflow: hidden`.
   - Solusi: Menambahkan `min-height: 240px; height: auto; object-fit: contain;` pada elemen gambar banner di kanvas.

### B. Transformasi Layout Hybrid (WordPress Gutenberg Fullscreen Mode)
1. **Halaman Daftar Artikel (Table List View)**:
   - Dibungkus dengan komponen natif Directus `<private-view title="Daftar Artikel">`.
   - Memunculkan kembali sidebar kiri Directus (`#navigation`) yang diisi dengan navigasi filter status (**Semua, Diterbitkan, Draft, Arsip**) lengkap dengan *dynamic count badges*.
   - Menyederhanakan tampilan dengan menghapus sidebar kanan (`#sidebar`), serta memindahkan kotak pencarian cepat (`.dashboard-top-search`) langsung ke bagian atas tabel.
2. **Halaman Editor (Tulis Baru / Edit Artikel)**:
   - Menerapkan pendekatan **CSS Takeover (Fixed Fullscreen Overlay)** menggunakan `position: fixed !important; top: 0; left: 0; width: 100vw; height: 100vh; z-index: 99999; background: #fff;`.
   - Menutup seluruh header dan sidebar admin Directus saat dalam mode edit untuk memberikan pengalaman menulis layar penuh 100% bebas distraksi ala WordPress Gutenberg / Notion.

### C. Refinement UI/UX (Clean & Icon-Only Philosophy)
1. **Tombol Tulis Baru (`+`)**: Mengganti teks tombol "Tulis Baru" pada header aksi Directus (`#actions`) menjadi tombol ikon bulat tunggal (`icon round`) dengan ikon `add` (`+`).
2. **Tombol Aksi Ikon Tunggal**: Menyeragamkan seluruh tombol sekunder di editor menjadi tombol ikon bulat:
   - Tombol Ganti Cover: Ikon `edit`.
   - Tombol Hapus Cover: Ikon `delete`.
   - Tombol Tambah Iklan & Sponsor: Ikon `add` (`+`).
   - Tombol Kembali ke Daftar: Ikon `arrow_back`.
3. **Penghapusan Seluruh Opsi Pratinjau (No Preview Clutter)**:
   - Menghapus tautan aksi "Pratinjau" dari baris tabel di dashboard.
   - Menghapus tombol "Pratinjau" dari top bar editor.
   - Menghapus simulasi Google SERP Preview dari sidebar kanan tab SEO agar penulis dapat langsung fokus pada pengisian metadata dan evaluasi skor SEO.

### D. Fitur SEO Analyzer & Pillar Content
1. **Smart Chip Tag Keywords**: Menggabungkan input Focus Keyword (ditandai bintang ★) dan Secondary/LSI Keywords ke dalam satu kolom tag berinput koma/enter dengan pewarnaan *real-time* (Hijau/Oranye/Merah) sesuai keberadaan keyword di konten dan judul.
2. **Keyword Cannibalization Check**: Pengecekan asinkron dengan debounce 800ms ke API Directus (`filter[SEO][_contains]`) untuk mencegah penggunaan keyword utama yang sama di artikel lain.
3. **Pillar Content Hierarchy**: Menggantikan checkbox sederhana dengan toggle `is_pillar` dan dropdown dinamis `pillar_parent` yang mengambil daftar artikel pilar lainnya via API.

### E. Penyelesaian Bug Z-Index Deadlock & Backdrop Modal (Aturan Emas)
1. **Modal Deadlock Fix (UI Freeze)**:
   - Masalah: Mengklik tombol pilih gambar atau iklan saat berada dalam overlay `.editor-view` menyebabkan layar freeze (tidak bisa diklik). Hal ini karena `.editor-view` menggunakan `z-index: 99999`, sedangkan modal `<v-dialog>` Directus berada di `z-index: 500-1000`, sehingga modal terbuka di belakang overlay dan *backdrop focus trap*-nya mengunci layar.
   - Solusi: Menurunkan `z-index` `.editor-view` menjadi `150` (cukup tinggi untuk menutupi navigasi Directus di kisaran 20-100, tapi di bawah modal dialog).
2. **Backdrop Stacking Fix (Blocked by Blue Background)**:
   - Masalah: Menimpa `z-index` `.v-dialog` dan `.v-overlay` secara paksa ke angka yang sama (`999999`) menyebabkan overlay transparan bertumpuk di atas card dialog sehingga dialog terlihat namun tidak bisa diklik.
   - Solusi: Menghapus total override global dan membiarkan Directus mengelola hierarki z-index modalnya secara natif (`.v-overlay` di 999, `.v-dialog` card di 1000).

## 3. Standardisasi Alur Kerja Ekstensi (For Future AI & Devs)
Ditetapkan alur kerja baku untuk setiap modifikasi kode di folder `extensions/`:
```bash
# 1. Build
cd /home/famanca/voda-tour-event/extensions/<nama-modul>
npm run build

# 2. Deploy ke Docker & Fix Perms
cd /home/famanca/voda-tour-event
docker cp extensions/<nama-modul>/dist/. voda-directus:/directus/extensions/<nama-modul>/dist/
docker exec -u root voda-directus chmod -R 777 /directus/extensions

# 3. Restart Directus
docker restart voda-directus
```
